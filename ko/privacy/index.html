개인정보 처리방침

시행일 2026년 10월 24일

Hoverstone 앱은 개인정보를 수집하거나 저장하지 않습니다. 회원가입, 사용 통계, 광고, 추적 기능이 없으며, 앱 사용 내용은 개발자에게 전송되지 않습니다.

1. 기기에 저장되는 정보

탭, 웹앱, 방문 기록, 설정, 사이트 로그인 정보는 사용자의 맥에만 저장됩니다. 흔적 지우기 또는 앱 삭제로 언제든 지울 수 있으며, 시크릿 탭의 기록은 시크릿 탭을 모두 닫으면 삭제됩니다.

2. 앱의 외부 연결

사용자가 연 페이지 외에 앱은 다음 경우에만 외부에 연결하며, 사용자를 식별할 수 있는 정보는 보내지 않습니다.

  • 사이트 아이콘: 사이트에서 직접 받으며, 아이콘이 없는 경우 Google 아이콘 서비스에 해당 사이트의 도메인 이름을 보내 요청합니다.
  • 광고 차단 목록: 공개된 차단 목록(easylist.to, adblockplus.org, jsdelivr.net)을 내려받습니다.
  • 구매: Pro 구매와 무료 체험은 Apple이 처리하며, 개발자는 결제 정보를 받지 않습니다.

사용자가 방문하는 웹사이트는 각 사이트의 개인정보 처리방침을 따릅니다.

3. 문의 메일

문의 메일을 보내시면 이메일 주소와 메일 내용은 답변에만 사용합니다. 삭제를 원하시면 같은 주소로 요청해 주세요.

4. 방침 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
