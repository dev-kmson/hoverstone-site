Report a Problem

If Hoverstone isn't working right, email us in three steps. With the error details file attached, we can find the cause much faster.

1. Save the error details

Open Hoverstone's Settings, go to Report a Problem at the bottom and click Report. A file named Hoverstone Error Details (date).txt is saved to your desktop, and this page opens.

If the app won't open

In Finder, press ⌘⇧G, paste the path below, and copy Hoverstone.log to your desktop.

~/Library/Containers/com.minihandz.Hoverstone/Data/Library/Logs

2. Write the email

Send these to hoverstone.support@gmail.com:

  • What went wrong
  • What you were doing just before it happened
  • The site's address, if it happened on a particular site
  • Whether it happens again if you try the same thing

No need to mention your app or macOS version. The error details file has both.

3. Attach files

Attach the error details file you saved.

A screenshot or screen recording of the problem helps even more. Press ⌘⇧5 to take one.

What's in the error details

Only the kinds of errors that happened in the app, the app and macOS versions, and which features are switched on. It never contains the sites you visit, your searches, what you type or file names. It stays on your Mac and keeps only the last 7 days.

A file you send us is used only to look into the problem and is deleted once that's done. See the Privacy Policy for more.
